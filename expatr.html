PBInfo 2600: expatr - solutie

Cerinta

Scrieți un program care citește de la tastatură un număr natural a și care afișează partea întreagă a valorii expresiei (3*(a^2+a^4))/(a^2+a^4+sqrt(a^2+a^4))+sqrt(a^2+a^4).

Date de intrare

Programul citește de la tastatură numărul a.

Date de ieşire

Programul va afișa pe ecran numărul un număr natural, reprezentând rezultatul cerut.

Restricţii şi precizări

1 ≤ a ≤ 100

Exemplu:

Intrare

2
Ieșire

6

Solutie


#include <iostream>
#include <math.h>
using namespace std;
int main()
{
    int a,b;
    cin>>a;
    b=(3*pow(a,2)+3*pow(a,4))/(pow(a,2)+pow(a,4)+sqrt(pow(a,2)+pow(a,4)))+sqrt(pow(a,2)+pow(a,4));
    cout<<b;
    return 0;
}
