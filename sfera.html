PBInfo 3810: sfera - solutie

Cerinta

Se dă raza unei sfere. Aflați aria și volumul sferei.

Date de intrare

Programul citește de la tastatură numărul r, reprezentând raza sferei.

Date de ieşire

Programul va afișa pe ecran numerele A și V, reprezentând aria și volumul sferei, cu 2 zecimale exacte, fără rotunjire.

Restricţii şi precizări

1 ≤ r ≤ 1000

Exemplu:

Intrare

5
Ieșire

314.15 523.59

Solutie


#include <iostream>
#include <math.h>
#include <iomanip>
using namespace std;
int main()
{
    double r,A,V;
    cin>>r;
    A=(4*M_PI*r*r);
    V=(4*M_PI*r*r*r)/3;
    A=A*100;
    V=V*100;
    A = (long long) A;
    V= (long long)  V;
    A = A/100;
    V = V/100;
    cout<<fixed<<setprecision(2)<<A<<" ";
    cout<<fixed<<setprecision(2)<<V;
    return 0;

}
